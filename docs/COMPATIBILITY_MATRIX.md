# PhoneCam Compatibility Matrix

> **Status:** Template. Filling a published compatibility matrix is not
> scheduled. Community reports for other distros, phones, and apps are welcome.

This file records app and platform compatibility evidence. It is not a release
gate.

## Required v0.1 Apps

- Chromium browser preview.
- Firefox browser preview.
- Google Meet.
- Zoom.
- Discord.
- OBS.

## Required Fields

Each compatibility entry should include:

- distro,
- kernel version,
- desktop/session,
- app/browser version,
- virtual camera device,
- `v4l2loopback` parameters,
- pixel format,
- pass/fail result,
- notes.
